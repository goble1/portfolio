## Custom wood nano leaf 

### Design

The code mostly uses the FastLED library setting up so the number of LEDS per boxs and the number of boxes. you can then select different random colors, fade time, and mode as a binary blink, twinkle, or a static color. Its controlled with bluetooth app that has a color scale and the different modes. the wiring it self is semple. I used a 5v source to powor the leds and the microcontroller. I later fonud the end of the led strip fading a bit so I added more power half way through the leds. the signal from the microcontroller was to week so I had to add a level converter to increase the signal to the led strip.
[link to code](github.com/goble1/hexleaf)

### Parts
- voltage regulator
- led light strip
- wood for making the blocks
- ELEGOO Nano V3.0 Board 
- foggy plastic shelf liners 
- logic shifter
